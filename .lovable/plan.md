# Zisaura Website Redesign

## Goal
Rebuild the full Zisaura site as a premium, industrial-modern U.S. B2B presence that explains the integrated offer immediately and earns trust without unsupported claims.

## Build
- Replace the current homepage with a responsive, dark technical design based on the selected direction.
- Create a premium desktop and mobile navigation with working links to Services, How It Works, About, FAQ, and Contact.
- Build the supplied sections: hero and operating-system visual, problem, services, benefits, five-step process, ideal customer, expansion path, transparency, FAQ, booking area, final call to action, and footer.
- Use restrained blue accents, precise borders, professional icons, strong typography, generous spacing, and subtle motion with reduced-motion support.
- Make every booking button open an honest calendar placeholder panel until a real booking URL is supplied; keep email as the secondary contact method.
- Remove every fabricated statistic, testimonial, company-size claim, compliance claim, and unsupported result from the current site.
- Add dedicated Privacy Policy and Terms of Service pages so footer links work, each with route-specific metadata.
- Apply the supplied page title and description, accessible semantics, focus states, smooth scrolling, and mobile-friendly controls.

## Technical details
- Keep the site in TanStack Start with separate routes for legal pages.
- Define all visual colors and shadows as semantic tokens in the global stylesheet.
- Use Lucide icons and small focused React components for repeated sections.
- Update the root font links and remove Lovable-branded metadata.
- Verify the site in desktop and mobile browser views, check navigation and booking interactions, then confirm the latest build is clean.
